Carregue a base de dados para começar

O arquivo Excel precisa ter uma aba com "Despesas" no nome e outra com "Receitas" no nome — em qualquer posição do nome, com ou sem o ano. As colunas podem estar em qualquer ordem: o painel encontra cada uma pelo texto do cabeçalho. Sempre que a base mudar, use o botão "Carregar base de dados" de novo para atualizar tudo. Depois de carregar, use "Salvar painel com estes dados" para gerar um arquivo que já abre com as informações prontas — quem receber não precisa do Excel.
