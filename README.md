# Painel Financeiro — IGESDF

Painel interativo de execução orçamentária do Contrato de Gestão nº 001/2018 (IGESDF · SES/DF).

## Como usar

1. Abra a página publicada (veja o link em **Settings → Pages** deste repositório, ou acesse diretamente pelo GitHub Pages).
2. Clique em **"Carregar base de dados (.xlsx)"** e escolha o arquivo Excel com as abas de Despesas e Receitas.
3. Use os filtros (período, unidade, fonte, grupo, plano de contas, natureza) para explorar as 7 tabelas fixas e a tabela dinâmica.
4. Para compartilhar com alguém sem que a pessoa precise do Excel, use **"Salvar painel com estes dados"** — isso baixa uma nova cópia do arquivo já com os dados embutidos.

## Aviso importante sobre privacidade

Este arquivo (`index.html`), do jeito que está neste repositório, **não contém nenhum dado financeiro** — ele só carrega quando alguém importa o Excel na própria máquina, e nada é enviado para servidor nenhum.

**Cuidado:** se você gerar uma versão com dados embutidos (pelo botão "Salvar painel com estes dados") e subir *essa* versão para este repositório, os dados financeiros ficam visíveis para qualquer pessoa que tiver o link — porque este é um repositório **público** do GitHub Pages. Para manter os dados fora do ar público, mantenha apenas a versão vazia aqui, e continue compartilhando as versões com dados por e-mail ou pasta compartilhada, como já vem sendo feito.
